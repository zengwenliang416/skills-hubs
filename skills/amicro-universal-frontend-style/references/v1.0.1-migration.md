# Migrating from v1.0.0 to v1.0.1

1. Replace the Skill installation with the v1.0.1 runtime package.
2. For an existing copied style layer, run the v1.0.1 installer with `--update` only when a `.amicro-install.json` manifest exists. Legacy copies without a manifest should be backed up and installed into a clean destination.
3. Review local overrides of `--amicro-text-muted`; the bundled light value changed to `#6f6f6f`.
4. Ensure the scope root has `.amicro`, `data-amicro-scope`, or `data-amicro-root`.
5. Remove active animation declarations that live outside `prefers-reduced-motion: no-preference`.
6. Replace dual accessible text labels with one text node or synchronize `hidden` plus `aria-hidden`.
7. Update automation that passes absolute `--output` paths; reports must now use target-relative paths.
8. Re-run strict verification and rendered checks at 320, 360, 768, and 1440px.
