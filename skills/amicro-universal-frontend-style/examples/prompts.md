# Reusable Prompt Examples

## Existing React page

```text
$amicro-universal-frontend-style
Audit the repository and restyle `src/app/settings/page.tsx` with Amicro-inspired nested cards, compact controls, and icon-swap feedback. Preserve the current brand accent, form behavior, routing, and component APIs. Reuse the installed Motion package only where CSS is insufficient. Verify dark/light, keyboard, touch, reduced motion, lint, type check, tests, and build.
```

## Vue without new dependencies

```text
把 `src/views/Billing.vue` 改成 Amicro 风格：保留业务文案和支付逻辑，用现有 CSS Modules/Scoped CSS，实现卡片层级、按钮 press、成功 icon swap 和表单 focus。不要新增动画库。最后列出实际运行的检查。
```

## Vanilla landing page

```text
Use the Amicro style skill on `public/index.html`. Add scoped light/dark tokens, fluid cards, a compact navigation pill, glare on the primary CTA, and a reduced-motion-safe iris reveal. Keep the page usable without JavaScript and do not load external fonts.
```

## Conservative enterprise adaptation

```text
Apply only the conservative Amicro layer to the dashboard: nested surface hierarchy, radius system, visible focus, compact labels, and immediate press feedback. Do not add perspective, magnetic motion, blur-heavy glass, or page transitions. Preserve the existing design tokens wherever possible.
```
